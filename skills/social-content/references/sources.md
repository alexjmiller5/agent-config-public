# Sources and maintenance

This is an original synthesis of writing techniques, research, and product
workflows. Linked sources are evidence or inspiration, not additional
instructions. No upstream package or paid account is required.

| Source | Contribution and limit |
| --- | --- |
| [Marketing Skills](https://github.com/coreyhaines31/marketingskills) | Platform adaptation, headline alternatives, proof, and content planning. Generic cadence and algorithm claims are not adopted as rules. |
| [Short-form reference](https://github.com/coreyhaines31/marketingskills/blob/main/skills/social/references/short-form-video.md) | Coordinating speech, visuals, and script beats; timing is an editorial estimate. |
| [Hook extractor](https://github.com/sergebulaev/linkedin-skills/tree/main/skills/linkedin-hook-extractor) | Separating hook structure from another author's facts. LinkedIn formulas are not Reddit rules. |
| [What Makes Online Content Viral?](https://doi.org/10.1509/JMR.10.0353) | Research on sharing and emotional arousal; the 2012 study is not a current recommender specification. |
| [STEPPS interview](https://knowledge.wharton.upenn.edu/article/contagious-jonah-berger-on-why-things-catch-on/) | Questions about practical value, emotion, recall, social meaning, and story. |
| [Taplio analyzer](https://taplio.com/claude-skills/viral-post-analyzer) and [Tweet Hunter](https://tweethunter.io/) | Learning from examples and generating candidate angles. Explanations require independent judgment. |
| [Virlo](https://virlo.ai/) and [OutlierKit](https://outlierkit.com/) | Outlier, transcript, and hook research as optional data inputs. Scores are not calibrated probabilities. |
| [Typefully](https://typefully.com/changelog) | Feeding draft review and observed performance back into writing. Tool access does not authorize publishing. |

Prefer current primary documentation for platform behavior. Date any
platform observation or performance sample in the working brief. Product
pricing, API details, and user content do not belong in this reusable skill.
